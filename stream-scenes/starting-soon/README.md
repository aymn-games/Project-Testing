# مشهد بداية البث — Stream Starting Soon

مشهد ثلاثي الأبعاد 1920×1080 مدته 26 ثانية (Three.js 0.160.0 بدون أدوات بناء).
يشتغل كمصدر متصفح في OBS، أو كفيديو MP4 جاهز.

## التشغيل في OBS
Browser Source ← الرابط:
`https://aymngames.online/stream-scenes/starting-soon/` — العرض 1920 والارتفاع 1080.

| الخيار بالرابط | وش يسوي |
|---|---|
| (بدون) | يعيد المشهد بشكل متكرر |
| `?once` | يشتغل مرة وحدة ويوقف على شاشة سوداء |
| `?t=12` | يبدأ من الثانية 12 (للمعاينة) |
| `?capture` | وضع التصدير: بدون حلقة، ويوفّر `window.__renderAt(t)` |

## الخط الزمني
| الوقت | الحدث |
|---|---|
| 0–1.4 | ظهور من الأسود، الكاميرا تقترب من بعيد |
| 1.3–4 | الحلقات والهالة تتركب، الكريستالات تطلع |
| 4.2–7 | حروف «STREAM STARTING» ثم «SOON» تطير من العمق وتلف بثلاثي أبعاد |
| 7.05 | موجة صدمة على الأرضية لما تنزل «SOON» |
| 7.6–18.4 | النصوص الجانبية + لمعة ضوء تمر على الحروف كل 4.5 ثانية |
| 18.5–20.3 | الحروف تتفرق وتختفي |
| 20.6–24.3 | الكاميرا تخترق الهالة مع فلاش |
| 24.3–26 | تلاشي للأسود |

كل الحركة دالة في الوقت فقط، فالتصدير مطابق للعرض الحي فريم بفريم.

## الخطوط
Unbounded وSpace Grotesk (رخصة SIL OFL 1.1). خط النص ثلاثي الأبعاد محوّل إلى `unbounded-800.typeface.json`،
ويحتوي حروف A–Z والأرقام فقط. لو تبي تغيّر النص لحروف ثانية، لازم تعيد تحويل الخط.
