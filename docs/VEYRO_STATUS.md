# فيرو (Veyro): الوضع الحالي وآخر التحديثات

> ملخص لبدء محادثة جديدة. آخر تحديث: 2026-11-19.
> التفاصيل الكاملة بـ`docs/VEYRO_SERVER.md` و`docs/CHANGELOG.md`.

## وش هو فيرو
منصة شاشات البث (أوفرلي) لـOBS وTikTok LIVE Studio، من منظومة ألعاب أيمن. فيها:
- **أدوات البث:** أليرتات فيديو، توب، أهداف، وعاء هدايا، نصوص، أدوات صوت.
- **إحصائيات البث.**
- **Streamlabs.**

**مرحلة تجربة:** للأدمن وحسابات «تجربة Veyro» بس (`PREVIEW_ADMIN_ONLY = true` بـ`veyro/studio.js`).

## آخر التحديثات (نوفمبر 2026)
1. **سيرفر مستقل:**
   - فيرو له سيرفر وقاعدة بيانات وقرص، واتصال تيك توك بمفتاح EulerStream خاص.
   - نشر الألعاب ما يوقف فيرو، والعكس.
   - الدخول بحساب ألعاب أيمن: فيرو يتأكد عند سيرفر الألعاب ويحفظ النتيجة، فيكمل لو سيرفر الألعاب توقف.
   - رابط OBS ما يحتاج سيرفر الألعاب أبداً.
   - البيانات انتقلت: 30 شاشة، 7 فيديوهات، 23 حساب.
   - سيرفر الألعاب بوضع التحويل (`VEYRO_API_URL`): طلبات فيرو القديمة تروح لسيرفر فيرو.
2. **التصميم:**
   - رجعت الألوان (لافندر) والخلفية ولمعة الماوس.
   - الأزرار والخيارات بشكل خاص «الحافة المشطوفة»: زاويتين مستديرة واثنتين حادّة، وإطار متدرّج.
   - الخيار المختار فيه نقطة مضيئة، والبلاطات فيها زاوية مطوية بـ✓.
   - مفتاح التبديل بمقبض «حجر»، والألوان على شكل قطرة.
   - جرّبنا تصميم على مبادئ Apple ورجّعناه بطلب صاحب المنصة.
3. **وعاء الهدايا:**
   - زجاج حقيقي بدون غطا: فتحة بيضاوية، وانعكاسات، وقاع سميك. والهدايا تطيح من فوق الفتحة.
   - هدايا التجربة صور تيك توك الحقيقية من `assets/tiktok-gifts/icons/`.
4. **أليرت الفيديو** (الصورة والاسم والرسالة فوق الفيديو):
   - **«مقاس موحّد»:** تكبّر وحدة والباقي يتبعها بنفس النسبة.
   - **زر «ستايل» جنب كل عنصر:** يفتح الشكل، واللون، والخط، وستايل النص، والحركات تحت صفه.
   - **«حركة مستمرة» جديدة:** يطفو، نبض، تمايل، نطّة، لمعة، دوران للصورة، موجة للنص.

## Render (الإعدادات الحالية)
| الخدمة | Root Directory / الفلتر | ملاحظات |
|---|---|---|
| `Project-Testing` (الألعاب) | Root = `backend` | فيها `VEYRO_API_URL` و`VEYRO_EXPORT_SECRET` |
| `veyro-api` (فيرو) | Root = `veyro-server` | Starter، قرص 1GB على `/var/data`، Health Check `/api/veyro/health` |
| `agp-platform` و`agp-dashboard` (الموقع) | يتجاهل `backend/**` و`veyro-server/**` و`docs/**` | مواقع ثابتة، ما تتوقف وقت النشر |

**متغيرات `veyro-api`:**
- `NODE_ENV`
- `CORE_API_URL`
- `FRONTEND_BASE_URL`
- `PUBLIC_API_BASE_URL`
- `EULERSTREAM_API_KEY` (مفتاح `Veyro-Production`)
- `YOUTUBE_API_KEY`
- `VEYRO_EXPORT_SECRET` (مؤقت)

## قواعد مهمة للشغل على فيرو
- **ملفات منسوخة:** بعض ملفات `veyro-server/` منسوخة من `backend/` (اتصال تيك توك، إحصائيات البث، الشاشات، Streamlabs). التعديل بواحد **ما ينتقل** للثاني:
  - لو يخص فيرو، عدّله بالنسختين.
  - الفروق عن الأصل معلّمة بتعليق «فيرو:».
- **الاختبارات:**
  - `cd veyro-server && npm test` (70 اختبار)
  - `cd backend && node --test`
- **قبل الدمج:** اختبر بصرياً بالمتصفح.
- **التشغيل محلياً:**
  - سيرفر الألعاب على 8787.
  - `cd veyro-server && npm install && CORE_API_URL=http://localhost:8787 node server.js` على 8788.
