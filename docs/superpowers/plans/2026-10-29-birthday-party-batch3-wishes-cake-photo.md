# حفلة عيد الميلاد — الدفعة 3 (التهاني، الكيكة، الصورة الجماعية، النقاط) خطة التنفيذ

> **للمنفّذين:** مهارة لازمة: superpowers:executing-plans (التنفيذ المباشر). الخطوات بصيغة مربعات (`- [ ]`).

**الهدف:** بعد وقت الرقص تكمل الحفلة تلقائياً لين النهاية:
- **التهاني:**
  - الكل يتجمّع قدام المنصة، وتنزل **شاشة التهاني** من السقف.
  - كل ضيف يكتب رسالته من جواله.
  - صاحبة الحفلة تضغط «التالي» وتنعرض الرسالة عند الكل، وتقدر ترقص وتلوّح.
- **الكيكة:** الكل حول المنصة، وصاحبة الحفلة قدام الكيكة تضغط «قص الكيكة». بعدها **احتفال ثاني** (ألعاب نارية، وليزر بألوان ثانية، وكونفيتي، وموسيقى ثانية).
- **الصورة:** **صورة جماعية**: الكل يترتب حول صاحبة الحفلة، وعد تنازلي ثم فلاش، والصورة تنحفظ بالجوال.
- **النقاط:** نقاط المنصة تنرسل للحسابات الموثّقة.
- **النهاية:** مرحلة `free`، القاعة مفتوحة.

**البنية:** نفس الدفعة 2.
- السيرفر يملك المراحل وأهداف المشي ورسائل التهاني.
- كل جوال يحسب المشي التلقائي بنفسه.
- النقاط تنرسل من جهاز المذيع (لازم يكون مسجّل دخول)، والقائمة يعطيه إياها السيرفر.

**وثيقة التصميم:** `docs/superpowers/specs/2026-10-28-birthday-party-design.md` (القسم 6، المراحل 4-6، والقسم 9).

## قيود عامة

- **ترتيب المراحل الكامل:**
  `lobby` ← `entrance`(40ث) ← `reveal`(12ث) ← `dance` ← `gather`(12ث) ← `wishes` ← `cakeWalk`(10ث) ← `cake` ← `celebrate`(30ث) ← `photo`(16ث) ← `free`
- **مراحل الحركة فيها ممنوعة (تلقائية):** `entrance` و`reveal` و`gather` و`cakeWalk` و`photo`.
- **التهاني:**
  - مدة `wishes` يحددها المذيع بين 2 و20 دقيقة، والافتراضي 8.
  - **الانتهاء:** المرحلة تنتهي بأي وحدة من هذي:
    - المذيع يضغط «تخطي».
    - صاحبة الحفلة تضغط «التالي» بعد آخر رسالة.
    - انتهاء المدة.
  - الرسالة من 1 إلى 200 حرف. كل ضيف له رسالة وحدة، ويقدر يعدّلها قبل ما تنعرض. ترتيب العرض حسب أول إرسال.
  - صاحبة الحفلة والمذيع ما يكتبون رسائل.
- **`cake` ما لها وقت:** تنتهي لما صاحبة الحفلة تضغط «قص الكيكة» (`cut`) أو المذيع يتخطى.
- **مواقع المشي:**
  - `gather`: الضيوف في شبكة الدفعة 2 قدام المنصة، وصاحبة الحفلة `(0, -36.5)` تواجه الضيوف.
  - `cakeWalk`: صاحبة الحفلة `(0, -37.6)` تواجه الكيكة (`ry = π`)، والضيوف نفس الشبكة.
  - `photo`: صاحبة الحفلة `(0, -29.6)` تواجه المنصة (`ry = π`)، والضيوف صفوف وراها. 18 بالصف، والمسافة 1.15م، والصف r عند `z = -29.6 + 1.2r`. الكاميرا من المنصة.
- **الرسائل بين الجوال والسيرفر:**
  - من العميل:
    - `wish {text}`: ضيف بس، ووقت `wishes` بس.
    - `next`: صاحبة الحفلة أو المذيع.
    - `cut`: صاحبة الحفلة أو المذيع.
    - `hideWish {id}`: المذيع بس.
    - `pointsDone`: المذيع.
  - من السيرفر:
    - `wishes {cur: {i, name, text} | null, shown, total}` للكل.
    - `wishList {items: [{id, name, text, hidden, shown}]}` للمذيع بس.
    - `myWish {text}` لكاتبها.
    - `points {players: [{id: 'tiktok:<u>', name}], durationMs}` للمذيع، مرة وحدة لين يرد `pointsDone`.
- **فلتر الكلمات:** قائمة صغيرة ثابتة (عربي وإنجليزي)، والكلمة الممنوعة تنستبدل بنجوم. المذيع يقدر يخفي أي رسالة.
- **الأمان:** النقاط بس للحسابات الموثّقة بتيك توك (`pointsId`)، فالضيف السريع ما ينرسل اسمه أبداً.

## نقاط تحتاج انتباه في المراجعة

1. **ضيف يرسل رسائل كثيرة أو طويلة أو فيها HTML، أو يرسل وقت غير التهاني:** السيرفر يقصّها أو يرفضها، والعرض آمن بـ `textContent` أو `canvas`. (المهمة 1 والمهمة 4)
2. **صاحبة الحفلة تضغط «التالي» بسرعة، أو المذيع وصاحبة الحفلة يضغطون بنفس الوقت:** رسالة وحدة تتقدم لكل ضغطة، وما فيه قفز للكيكة بالغلط إلا بعد آخر رسالة. (المهمة 1)
3. **المذيع مو متصل وقت الصورة:** النقاط تنرسل أول ما يرجع، ومرة وحدة بس. (المهمة 2)
4. **جوال يرجع وسط التهاني أو الكيكة أو الصورة:** يشوف الرسالة الحالية والشاشة نازلة، والكيكة مقصوصة إذا انقصت. (المهمة 4)
5. **ضيف سريع اسمه يشبه يوزر تيك توك:** ما ياخذ نقاط ولا ينرسل اسمه. (المهمة 1)

### المهمة 1: المراحل الجديدة والتهاني والنقاط في `party-rooms.js`

**الواجهات:**
- `createRoom({ girlName, danceSec, wishesSec })`: `wishesSec` من 120 إلى 1200، والافتراضي 480.
- `addWish(code, id, text) → { ok, wishId }`، والأخطاء: `'phase'`، `'role'`، `'empty'`، `'shown'` (رسالته انعرضت ما تتعدّل).
- `hideWish(code, wishId, hidden)`
- `nextWish(code, byId) → { ok, cur, done }`:
  - `byId` لازم يكون صاحبة الحفلة. المذيع يستدعيها بـ `byId = 'host'`.
  - إذا ما فيه رسالة جاية تنتقل المرحلة لـ `cakeWalk` و`done = true`.
  - رسالة وحدة لكل استدعاء، والمخفي يتخطاه.
- `wishesState(code) → { cur, shown, total }`
- `wishList(code)`
- `cut(code, byId) → { ok }`: صاحبة الحفلة أو `'host'`، ووقت `cake` بس. ينتقل لـ `celebrate`.
- `pointsList(code) → { players, durationMs }`:
  - `players`: الحسابات الموثّقة بس (`'tiktok:' + tiktok_username`).
  - `durationMs`: من بداية `entrance`.
- `room.cakeCut` (bool) ينحط عند القص، و`phaseOf` يرجّعه (`cut: true`).
- `phaseOf.walk` يرجع لكل المراحل التلقائية اللي فيها مشي.
