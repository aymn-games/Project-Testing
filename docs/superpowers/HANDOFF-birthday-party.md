## 1) الفكرة باختصار

لعبة ثلاثية الأبعاد على `aymngames.online` لحفلة عيد ميلاد حقيقية لبنت. الحفلة الحقيقية بعد ~72 ساعة من بداية 2026-10-28، يعني تقريباً **2026-10-31**.

**الأشخاص والدخول:**
- كل الحضور ناس حقيقيين، بما فيهم صاحبة الحفلة، يدخلون من جوالاتهم بالباركود. الشاشة بالعرض (landscape)، وكل جوال يرسم المشهد بنفسه.
- **المذيع** (صاحب المشروع) ينشئ الحفلة من صفحة خاصة.
- **الحد:** حتى 100 ضيف.

**مجرى الحفلة (كله يديره السيرفر):**
1. **الانتظار:** الضيوف في صالة، وصاحبة الحفلة في غرفتها.
2. **الدخول:** مشي تلقائي. هي من طريق مخفي لين ورا الستارة.
3. **الافتتاح:** الستارة تنفتح مع ألعاب نارية.
4. **الرقص.**
5. **التهاني:** شاشة كبيرة، والضيوف يكتبون، وهي تضغط «التالي».
6. **الكيكة:** تقصها، ثم احتفال ثاني.
7. **الصورة الجماعية.**
8. **بعدها:** القاعة مفتوحة.

**مؤجل لبعدين:** ألعاب تفاعلية داخل الحفلة.

**وثيقة التصميم المعتمدة:** `docs/superpowers/specs/2026-10-28-birthday-party-design.md`

## 6) الاختبار والبيئة (عشان ما تضيع وقت)

**الاختبارات:**
```bash
cd /home/user/project-testing && timeout 110 node --test 'backend/party/*.test.js' games/birthday-party/party-net.test.mjs 2>&1 | grep -E "^# (pass|fail)|^not ok"
```
**دايماً حط `timeout`:** اختبار ينتظر إغلاق اتصال ممكن يعلّق.

**تشغيل محلي:**
- **السيرفر** (بالخلفية، `timeout` طويل):
  ```bash
  cd backend && PARTY_ENABLED=1 PARTY_HOST_KEY=k PARTY_MAX_ROOMS=50 node server.js
  ```
  يشتغل على `:8787`. `PARTY_MAX_ROOMS=50` لأن كل اختبار ينشئ غرفة.
- **الملفات:** `python3 -m http.server 8765` من جذر المشروع.
- **عناوين محلية:** الجوال على `localhost` يتصل تلقائياً بـ `:8787`.

**Playwright:** مثبّت. السكربتات القديمة في مجلد الـ scratchpad القديم، فممكن ما تكون موجودة بجلسة جديدة. أعد كتابتها على نفس الفكرة:
- **مكتبات CDN محجوبة:** `cdn.jsdelivr.net` محجوب، فوجّهه لنسخة محلية:
  ```js
  p.route('https://cdn.jsdelivr.net/npm/three@0.160.0/**', r => r.fulfill({ path: '<three>/build/three.module.js' }))
  ```
  ونفس الشي لـ `qrcode-generator@1.4.4`.
  النسخ المحلية: `npm pack three@0.160.0` و`qrcode-generator@1.4.4`، وفكّها.
- **WebGL:** شغّل كروميوم بـ `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`.
- **الذاكرة:** **صفحة WebGL وحدة بس بكل مرة.** صفحتين سوّت OOM.
- **التدفق النموذجي:**
  1. المذيع والبوتات والبنت من Node عبر `WebSocket`.
  2. الجوال صفحة Playwright: `join.html` ← `quickBtn` ← `play.html`.
  3. التنقل بين المراحل بـ `{t: 'skip', from}` من المذيع.
- **البوتات:** لازم ترسل `{t: 'ping'}` كل 10ث، وإلا تنقطع بعد 40ث (idle timeout).
- **حقن شخصيات للقطات:** `__crowd.sync([...real, ...fakes])` ثم `setInterval(() => __crowd.apply(rows, Date.now()), 120)`، مع `__hall.debugView([0, 2.1, -12.2], [0, 1.15, -18.3])`.
- **لا تستخدم `pkill -f "node server.js"`:** يقتل الـ shell نفسه. استخدم `'^node server.js'` أو TaskStop.
- **فحص صيغة ملف ES module فيه import من CDN:** انسخه وبدّل الـ import بمسار محلي، ثم `node --check`.
