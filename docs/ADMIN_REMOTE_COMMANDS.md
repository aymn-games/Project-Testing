# دليل أوامر الأدمن — التحكم بأي بث

حساب الأدمن (`role = admin`) يتحكم بأي بث **صفحة ألعابه مفتوحة الحين**:
ما يحتاج الستريمر يضيفك، ولو طافي «التحكم عن بعد» تتحكم برضو.

- **الستريمر يدري:** أول ما تفتح لوحة التحكم على بثه تطلع عنده شارة
  «🛡️ الأدمن متصل بلوحة التحكم» تحت يسار الشاشة، وكل أمر تنفّذه يطلع
  عنده بإشعار يبدأ بـ«🛡️ الأدمن».
- **كل أمر يتسجّل:** وقت فتح اللوحة، وكل أمر، وكل لعبة تفتحها، سواء من
  الجوال أو الشات. تشوف آخر أوامرك بصفحة اختيار البث بـ`control.html`.
  السجل يبقى 90 يوم.

---

## 1) طريقتين للتحكم

### أ) من الجوال (الأسهل)
1. افتح **`aymngames.online/control.html`** وأنت مسجّل دخول بحساب الأدمن.
   (أو من بروفايلك ← «التحكم عن بعد» ← «كل البثوث»).
2. تطلع لك قائمة بكل البثوث المفتوحة الحين، وتحت كل ستريمر اسم اللعبة
   والشاشة اللي هو فيها (مثل «القنبلة · اللوبي»).
3. اختر الستريمر ← تشوف شاشته بالضبط: الإعدادات بقيمها، وأزرار اللعبة،
   وتبويب «الألعاب» لفتح أي لعبة، و«المكتبة» للرجوع لمكتبة الألعاب.
4. «تبديل البث» فوق تحت اسم الستريمر يرجّعك للقائمة.

### ب) بالشات (تكتب تعليق ببث الستريمر)
- لازم حساب الأدمن يكون **موثّق بيوزر تيك توك** (من «حسابي»)، وتعلّق من
  نفس حساب تيك توك هذا. الموقع يتعرّف عليك من معرّف تيك توك الثابت، مو من
  الاسم الظاهر، فما أحد يقدر ينتحل شخصيتك.
- كل أمر يبدأ بـ **`!`** (تنفع `!` أو `！`).
- الشات يشتغل لما تكون شاشة اللعبة عند الستريمر **متصلة بالبث**.
- النتيجة تطلع على شاشة الستريمر كإشعار صغير (✅ تم / ⚠️ السبب).

> الحروف ما تفرق: `!انهاء` = `!إنهاء` = `!انهاء`، و«ال» والهمزات والتاء
> المربوطة كلها تتطابق تلقائياً، والأرقام العربية تنقبل (`!الوقت ٢٥`).

## 2) أوامر عامة (تشتغل بأي شاشة)

| الأمر | وش يسوي | مثال |
|---|---|---|
| `!اوامر` | يعرض على شاشة الستريمر كل أوامر الشاشة الحالية (المرجع الأدق) | `!اوامر` |
| `!لعبه <اسم>` | يفتح إعدادات لعبة (بدون اسم يعرض قائمة الألعاب) | `!لعبه القنبلة` |
| `!المكتبه` | يرجع الستريمر لمكتبة الألعاب (ينهي اللعبة الحالية) | `!المكتبه` |
| `!اضغط <اسم الزر>` | يضغط أي زر ظاهر على شاشة الستريمر باسمه | `!اضغط ابدأ اللعبة` |

أسماء بديلة: `!العاب` و`!افتح` = `!لعبه`، و`!مكتبه` = `!المكتبه`، و`!زر` =
`!اضغط`، و`!مساعده` = `!اوامر`.

**`!اوامر` هي المرجع الأهم**: كل شاشة لها أوامرها، وهالأمر يعرضها كاملة
مع شرحها بنفس اللحظة.

### أسماء الألعاب لأمر `!لعبه`
الحلبة · روليت الإقصاء · روليت مخفي · الروليت الروسي · روليت الفواكه ·
الكراسي الموسيقية · القنبلة · الطمع · السلم والثعبان · تحدي الذاكرة ·
حظ و لون · سفينة النجاة · فورمولا ون · حجرة ورقة مقص · حرب الفريقين ·
الخزنة · إكس أو · شد الحبل · توصيل النقاط · ركلات الترجيح · أسرع إجابة ·
محِك العقول · خلية الحروف · كوّن كلمة · سلسلة الكلمات · اسم وحيوان ونبات ·
تحدي المفردات · خمّن العشرة · تحدي الصور · شخبليطة · كود نيمز · المافيا ·
محطة سهيل · حفلة الميلاد · من الأمبوستر؟

(يكفي جزء من الاسم: `!لعبه روليت الاق` تفتح روليت الإقصاء. الألعاب اللي
عليها «قريباً» بالجوال ما تنفتح عن بعد.)

## 3) أوامر شاشة الإعدادات (أغلب الألعاب)

كل إعداد ظاهر بشاشة الإعدادات صار أمر **باسمه**: تكتب اسم الإعداد ثم القيمة.

| النوع | الشكل | مثال |
|---|---|---|
| اختيار من خيارات | `!<اسم الإعداد> <الخيار>` | `!الصعوبة صعب` |
| رقم | `!<اسم الإعداد> <رقم>` | `!الحد الأقصى للاعبين 30` |
| تشغيل/إيقاف | `!<اسم الإعداد> تشغيل` أو `ايقاف` (بدون كلمة = يقلب الحالة) | `!الأصوات ايقاف` |
| نص | `!<اسم الإعداد> <النص>` | `!كلمة الدخول صقر` |
| البدء | `!ابدأ` | يحفظ الإعدادات ويفتح اللوبي |

كلمات التشغيل: تشغيل، شغل، فعل، فتح، نعم، on. وكلمات الإيقاف: ايقاف، وقف،
طفي، قفل، الغاء، لا، off.

## 4) أوامر اللوبي (أغلب الألعاب)

| الأمر | وش يسوي |
|---|---|
| `!ابدأ` (أو `!العب`) | يبدأ المباراة بلاعبين اللوبي |
| `!طرد <اسم>` (أو `!شيل`) | يشيل لاعب من اللوبي |
| `!رجوع` (أو `!الاعدادات`) | يرجع لشاشة الإعدادات |

## 5) أوامر خاصة ببعض الألعاب (أثناء اللعب)

### روليت الإقصاء 🎡
| الأمر | وش يسوي |
|---|---|
| `!لف` | يلف العجلة (جولة جديدة) |
| `!تلقائي [تشغيل/ايقاف]` | اللف التلقائي بعد كل دور |
| `!اقصاء <رقم أو اسم>` | إقصاء لاعب يدوياً (بدون اسم: صاحب الدور) |
| `!ارجاع <رقم أو اسم>` | يرجّع لاعب مُقصى |
| `!دخول [فتح/قفل]` | فتح/قفل دخول لاعبين جدد |
| `!اعادة` | مباراة جديدة بنفس اللاعبين (بعد الفوز) |
| `!جديدة` | مباراة جديدة من اللوبي (بعد الفوز) |
| `!انهاء` | **ينهي المباراة الحالية** ويرجع للوبي |
| `!الشكل <روليت/سكرول>` | شكل العجلة |
| `!الوقت <20/25/35>` | وقت الإقصاء بالثواني |
| `!الاصوات [تشغيل/ايقاف]` | الأصوات |
| `!الصديق [تشغيل/ايقاف]` | إرجاع صديق عند تكرار الاختيار |
| `!الدعم <اسم الهدية> [العدد]` أو `!الدعم ايقاف` | الرجوع عن طريق الدعم |
| `!الحالة` | يعرض حالة المباراة |

### روليت الفواكه 🍉
نفس أوامر روليت الإقصاء (`!لف`، `!اقصاء`، `!تلقائي`، `!دخول`، `!اعادة`،
`!جديدة`، `!انهاء`، `!الشكل`، `!الاصوات`، `!الدعم`، `!الحالة`)، وزيادة:

| الأمر | وش يسوي |
|---|---|
| `!صندوق` | يفتح الصندوق |
| `!اغلاق` (أو `!كمل`) | يقفل نافذة الصندوق ويكمل |
| `!خلط` | يخلط الفواكه |
| `!ايقاف` / `!اكمال` | إيقاف مؤقت / إكمال اللعب |
| `!المدة <...>` | المدة / الصعوبة |

### فورمولا ون 🏎️
| الأمر | وش يسوي |
|---|---|
| `!ابدأ` | يبدأ السباق (العد التنازلي) |
| `!انهاء` | **ينهي السباق** ويعرض الترتيب |
| `!جديد` | سباق جديد بنفس اللاعبين |
| `!تجربة` | تجربة بلاعبين وهميين (بدون نقاط) |
| `!شيل <رقم أو اسم>` | يشيل لاعب من الشبكة (قبل الانطلاق) |
| `!كاميرا <لقطة>` | تغيير لقطة الكاميرا |
| `!تابع <رقم أو اسم>` | تثبيت الكاميرا على لاعب |
| `!الرسوم <وضع>` | جودة الرسوم |
| `!لفات <1–20>` | عدد اللفات |
| `!الحد <1–30>` | الحد الأقصى للمتسابقين |
| `!كلمة <الكلمة>` | كلمة الدخول بالشات |
| `!المتابعين [تشغيل/ايقاف]` | الدخول للمتابعين فقط |
| `!المخرج [تشغيل/ايقاف]` | المخرج التلقائي للكاميرا |
| `!هدايا [تشغيل/ايقاف]` | تأثيرات الدعم |

| الأمر | وش يسوي |
|---|---|
| `!ابدأ` | يبدأ القتال |
| `!لوبي` | يفتح لوبي الدخول |
| `!تجربة` | لاعبين تجريبيين (بدون نقاط) |
| `!جديد` | جولة جديدة من اللوبي |
| `!اعادة` | إعادة بنفس اللاعبين |

### باقي الألعاب
أي زر ظاهر على الشاشة تقدر تضغطه بـ`!اضغط <اسم الزر>`. ومن الجوال تطلع
كل الأزرار والخانات جاهزة. اكتب `!اوامر` بأي شاشة عشان تشوف أسماءها
بالضبط.

## 6) سيناريوهات سريعة

| تبي | من الجوال | بالشات |
|---|---|---|
| تنهي لعبة شغّالة | زر «إنهاء» بالتحكم، أو «المكتبة» | `!انهاء` (لو اللعبة فيها) أو `!المكتبه` |
| تفتح لعبة معينة | تبويب «الألعاب» ← اللعبة | `!لعبه القنبلة` |
| تعدّل إعداد | غيّره من صفحة الإعدادات بالجوال | `!<اسم الإعداد> <القيمة>` |
| تبدأ المباراة | زر «ابدأ» | `!ابدأ` |
| تطرد لاعب | زر «طرد لاعب» ← اختر الاسم | `!طرد <اسم>` |
| ما تدري الأوامر | — | `!اوامر` |

## 7) حدود لازم تعرفها
- التحكم يوصل بس لبث **صفحة ألعابه مفتوحة** بالموقع. لو الستريمر قافلها
  ما يطلع بالقائمة.
- لو الستريمر فاتح الموقع بأكثر من تبويب، الأمر يروح للتبويب اللي ظاهر عنده.
- إذا الشاشة كانت تنتقل (من الإعدادات للوبي مثلاً)، الأمر ينتظر 8 ثواني
  ويتنفّذ أول ما تجهز الشاشة.
- أوامر الشات تحتاج حساب الأدمن موثّق بتيك توك. أما التحكم من الجوال فما
  يحتاج توثيق.
