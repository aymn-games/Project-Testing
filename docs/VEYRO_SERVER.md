# سيرفر فيرو المستقل (`veyro-server/`)

فيرو (شاشات البث) صار له سيرفر وقاعدة بيانات واتصال تيك توك خاص فيه، منفصل عن
سيرفر الألعاب (`backend/`). **نشر أي واحد منهم ما يوقف الثاني.**

| | سيرفر الألعاب `backend/` | سيرفر فيرو `veyro-server/` |
|---|---|---|
| يملك | الحسابات وتسجيل الدخول، النقاط، المتجر، الألعاب، التحديات، الإدارة | الشاشات، المكتبة (الفيديوهات)، Streamlabs، مفاتيح الصوت، «جرّب»، إحصائيات البث بفيرو |
| قاعدة البيانات | `agp-data.sqlite` على قرصه | `veyro-data.sqlite` + `screen-media/` على قرصه |
| اتصال تيك توك | اتصالات الألعاب | اتصاله الخاص: يفتحه لما شاشة فيها بيانات بث مفتوحة بـOBS، أو «اتصل بالبث»، أو «الحساب التلقائي» |
| مفتاح EulerStream | المفتاح الحالي | مفتاح منفصل (حده اليومي ما يأكل من الألعاب) |

## كيف يشتغلون مع بعض

- **تسجيل الدخول:** فيرو ما عنده حسابات. المستخدم يدخل بحساب ألعاب أيمن (`AGPAuth`)،
  وفيرو يتأكد من التوكن عند سيرفر الألعاب (`GET /api/veyro/whoami`) ويحفظ النتيجة
  (`veyro-server/core/core-auth.js`):
  - بالذاكرة 5 دقايق.
  - لو سيرفر الألعاب ما رد (نشر أو إعادة تشغيل)، يكمل بآخر نتيجة لين 24 ساعة.
  - آخر نتيجة محفوظة بقاعدة فيرو (`veyro_sessions`، بصمة التوكن بس)، فتنفع حتى لو
    فيرو نفسه انعاد تشغيله بنفس الوقت.
- **رابط الشاشة بـOBS** (`veyro/screen.html?k=`) ما يسأل سيرفر الألعاب أبداً: صاحب
  الشاشة ويوزر تيك توك محفوظين بقاعدة فيرو (جدول `users`، يتحدّث كل ما يدخل صاحبه).
- **الواجهة:** رابط سيرفر فيرو بمكان واحد: `VEYRO_API` بـ`js/agp-stream-overlay.js`.
  منه يقرأ محرر فيرو (`veyro/studio.js`)، والمحرر القديم (`overlay/studio.js`)، وروابط
  الشاشات. لو فاضي، الطلبات تروح لسيرفر الألعاب (الوضع القديم).
  أوفرلي صفحات الألعاب (بدون رابط شاشة) يبقى على سيرفر الألعاب.
- **الجسر بسيرفر الألعاب** (`backend/http/veyro-bridge.js`):
  - `whoami`.
  - التصدير لنقل البيانات (مقفل بسر).
  - **وضع التحويل:** لو `VEYRO_API_URL` موجود، أي طلب قديم لـ`/api/screens*`
    و`/api/public/screen*` و`/api/streamlabs*` يتحوّل لسيرفر فيرو كما هو، ومراقب
    الشاشات وStreamlabs بسيرفر الألعاب يوقفون.

## إنشاء الخدمة بـRender (مرة وحدة)

**Web Service جديدة** من نفس المستودع:

| الإعداد | القيمة |
|---|---|
| Name | `veyro-api` — الرابط الحالي: `https://veyro-api-7mj3.onrender.com` |
| Root Directory | `veyro-server` |
| Build Command | `npm ci` |
| Start Command | `node server.js` |
| Instance | Starter أو أعلى (لازم عشان القرص) |
| Disk | Mount Path = `/var/data`، الحجم 1GB يكفي البداية (الفيديو لين 50MB، والعدد حسب الباقة — راقب المساحة وكبّرها لما تمتلي) |
| Region | نفس منطقة سيرفر الألعاب |

**متغيرات البيئة لخدمة فيرو:**

| المتغير | القيمة |
|---|---|
| `NODE_ENV` | `production` |
| `CORE_API_URL` | رابط سيرفر الألعاب: `https://project-testing-akds.onrender.com` |
| `EULERSTREAM_API_KEY` | **مفتاح EulerStream الجديد الخاص بفيرو** |
| `VEYRO_EXPORT_SECRET` | سر عشوائي طويل — نفس القيمة بسيرفر الألعاب (للنقل بس) |
| `PUBLIC_API_BASE_URL` | رابط خدمة فيرو نفسها (مثل `https://veyro-api.onrender.com`) |
| `FRONTEND_BASE_URL` | `https://aymngames.online` |
| `YOUTUBE_API_KEY`، `GOOGLE_TTS_API_KEY` | انسخها من سيرفر الألعاب (مشغّل الأغاني والقارئ الصوتي) |
| `STREAMLABS_CLIENT_ID`، `STREAMLABS_CLIENT_SECRET` | انسخها من سيرفر الألعاب لو موجودة |
| `STREAMLABS_REDIRECT_URI` | اختياري — الافتراضي `PUBLIC_API_BASE_URL/api/streamlabs/oauth/callback`، ولازم يتحدّث بإعدادات تطبيق Streamlabs بنفس القيمة |
| `VEYRO_AUTO_CONNECT` | اختياري: `0` يقفل الاتصال التلقائي للشاشات المفتوحة |
| `VEYRO_STATS_WATCHER` | اختياري: `0` يقفل «الحساب التلقائي» |

## الانتقال (بالترتيب — كل خطوة ما توقف أحد)

1. **دمج الـPR:** الموقع وسيرفر الألعاب ينشرون. ما يتغيّر شي على المستخدمين: `VEYRO_API`
   فاضي، و`VEYRO_API_URL` مو موجود، والتصدير مقفل بدون السر.
2. **أنشئ خدمة فيرو** بالإعدادات فوق، وأضف `VEYRO_EXPORT_SECRET` لسيرفر الألعاب بنفس
   القيمة (يعيد التشغيل مرة).
3. **تأكد من النقل:**
   - افتح `https://<رابط فيرو>/api/veyro/health` (لازم `success: true`).
   - بسجل خدمة فيرو لازم يطلع `Import from games server: {...}` بعدد الشاشات والفيديوهات.
   - النقل يتكرر كل 10 دقايق طول ما السر موجود، فأي تعديل يصير بسيرفر الألعاب ينقل.
     وأي شي تحذفه بفيرو ما يرجع.
4. **فعّل التحويل:** أضف `VEYRO_API_URL` = رابط فيرو لسيرفر الألعاب (يعيد التشغيل مرة).
   من هنا كل طلبات فيرو، حتى القديمة، تروح لسيرفر فيرو.
5. **وجّه الواجهة لفيرو مباشرة:** حط رابط خدمة فيرو بـ`VEYRO_API` بـ`js/agp-stream-overlay.js`
   وادمج. الموقع ينشر بدون توقف، والمحرر وروابط OBS صارت تكلم فيرو بدون ما تمر على
   سيرفر الألعاب. **بعد هالخطوة الفصل كامل.**
6. **فلاتر النشر** (Settings ← Build & Deploy) عشان كل خدمة ما تنشر إلا لملفاتها:
   - سيرفر الألعاب: Root Directory = `backend`.
   - سيرفر فيرو: Root Directory = `veyro-server` (من الخطوة 2).
   - الموقع (Static Site): Build Filters ← Ignored Paths: `backend/**`، `veyro-server/**`، `docs/**`.
7. **بعد يوم أو يومين:** احذف `VEYRO_EXPORT_SECRET` من الخدمتين (النقل يوقف، والتصدير يتقفل).

**الرجوع لو صار شي:** فضّ `VEYRO_API` بالواجهة واحذف `VEYRO_API_URL` من سيرفر الألعاب.
كل شي يرجع يشتغل من سيرفر الألعاب. **انتبه:** التعديلات اللي صارت بفيرو بعد الانتقال ما
ترجع لسيرفر الألعاب.

## لوحة تحكم فيرو (`veyro/admin.html`)

لوحة للأدمن منفصلة عن لوحة أدمن ألعاب أيمن. الرابط: `https://aymngames.online/veyro/admin.html`.

- **مين يدخلها:**
  - أي حساب `role = admin` بألعاب أيمن يدخل كـ«مالك» بصلاحية كاملة.
  - المشرفين ينضافون من «الإعدادات» باللوحة نفسها، بثلاث صلاحيات:
    - **مدير:** كل شي ما عدا إدارة المشرفين.
    - **دعم:** يقرأ، ويضيف أيام، ويكتب ملاحظات، ويطبّق كود.
    - **محتوى:** المكتبة بس.
- **المعاينة:** `admin.html?demo` تفتح بيانات تجريبية بالمتصفح بس. وأي مكان برا الموقع يفتح التجريبي تلقائياً.
- **الكود:**
  - `veyro-server/admin/veyro-admin-service.js`: الجداول والمنطق.
  - `admin/admin-router.js`: المسارات والصلاحيات.
  - `admin/usage-tracker.js`: الساعات الفعلية.
- **المسارات:**
  - `GET /api/veyro/admin/snapshot`: كل بيانات اللوحة.
  - `POST /api/veyro/admin/op`: كل التعديلات.
  - `POST /api/veyro/admin/assets/upload?id=`: رفع ملف أصل.
  - للستريمر: `GET /api/veyro/me`، و`POST /api/veyro/me/redeem` (كود)، و`GET /api/veyro/library`.
  - `GET /api/auth/me` يرجع معه `veyro`: حالة الحساب، والاشتراك، والإعلان، وإعداد «للأدمن بس».
- **الساعات الفعلية:** وقت رابط شاشة فيرو مفتوح بـOBS أو TikTok LIVE Studio.
  - كل سؤال من الرابط لـ`/api/public/screen/events` يعتبر نبضة.
  - تنحسب مرة وحدة لكل ستريمر حتى لو فاتح أكثر من شاشة.
  - «على الهواء» = نفس الوقت والبث شغّال.
- **حالة الحساب:**
  - الموقوف والمحظور ما يفتح المحرر، وروابط شاشاته ترد 403.
  - «تسجيل خروج من كل الأجهزة» يرفض أي توكن انشاف قبله.
- **الاشتراك الإلزامي:** مطفي من البداية. لما تشغّله من الإعدادات، اللي ما عنده اشتراك نشط يطلع له «فعّل اشتراكك» وخانة كود. الأدمن والتجربة مستثنين.
- **«فيرو للأدمن بس»:** صار من إعدادات اللوحة. `PREVIEW_ADMIN_ONLY` بـ`studio.js` يُستخدم بس لو السيرفر ما رجّع الإعداد.
- **الحدود:** عدد الشاشات والفيديوهات يجي من خطة الاشتراك أو من حد مخصّص للحساب. بدونها تبقى حدود السيرفر العادية: 12 شاشة و10 فيديوهات.
- **مكتبة فيرو العامة:**
  - الملفات بـ`<DATA_DIR>/veyro-assets/`.
  - كل نوع وين يطلع بالمحرر:
    - **أليرت فيديو:** بـ«مكتبتي» تحت «من مكتبة فيرو»، ويشتغل بنفس رابط فيديوهات الشاشات.
    - **قالب توب:** بقسم «التوب» تحت «من مكتبة فيرو»، وبإعدادات أي توب تحت «قوالب من مكتبة فيرو». التصميم اسمه `design = 'tpl'`، وشكله بـ`it.tpl`.
    - **أيقونة:** بقسم «الأيقونات»، تبويب «من فيرو». الحقل `it.img = {id}`.
    - **صوت:** بإعدادات أليرت الفيديو، «صوت من مكتبة فيرو». الحقول `it.soundId` و`it.soundVol`، ويشتغل برابط الشاشة بس.
    - **إطار:** بستايل صورة الداعم بأليرت الفيديو، «إطارات من فيرو». الحقول `parts.avatar.fr = 'asset'` و`fa` و`fs`.
  - الأيقونات والإطارات اللي فيها تفريغ تنرفع PNG شفاف وقت النشر، لأن الشاشات تعرض الصورة كما هي.
  - **شكل الأليرت:** الأدمن يحدد من «شكل الأليرت للستريمرز» شكل أليرت الفيديو (`look` بإعدادات الأصل). ويوصل للستريمر لما يستخدمه، ويقدر يعدّله من «الألوان والخلفية» بالمحرر:
    - خلفية خلفه بلون وشفافية وحواف (`it.vbg`).
    - ألوان الفيديو: درجة اللون والتشبّع والسطوع (`it.vfx`).
    - لون جاهز يلوّن الأليرت كله (`it.vfx.tint`، من `ALERT_TINTS`)، ينختار من «مشاهدة» بالمكتبة أو من الإعدادات أو كافتراضي من الأدمن.
    - المكتبة فيها تبويبات تصنيفات (حقل `cat` بالأصل) وزر «مشاهدة».
    - ألوان الصورة والاسم والرسالة وظهورها (`it.parts`).
    - ملء الشاشة (`it.full`): الأليرت بحجم الشاشة كاملة، والفيديو contain بالوسط. وإذا مطفي، حجمه من `look.size`.
    - **شكلين** (`look.variants`، شغّال من البداية): الستريمر يشوف زرين، «مفرّغ» بدون خلفية، و«بخلفية» بإعدادات الخلفية اللي حددها الأدمن.
  - **معاينة الأليرت بلوحة الأدمن:** شاشة بث 1920×1080، والأليرت عليها بحجمه الحقيقي. وفيها زر صوت يشغّل صوت الفيديو، وخلفية «محاكاة بث» (`veyro/brand/stream-sim.svg`)، والخلفية نفسها موجودة بالمحرر وبأداة التفريغ.
  - **بطاقات الأليرتات بالمكتبة:** خلفية ثابتة `veyro/brand/library-bg.webp` وشعار فيرو بالنص. تتغيّر لما تبدّل الملف.
  - الرسم بـ`js/agp-stream-overlay.js` (`assetUrl`، `playAssetSound`، `tplTop`)، و`LIVE_VERSION = 5`.
- **الدفع من متجر الألعاب:**
  - **المنتج:** بلوحة المتجر، أنشئ منتج تسليمه «اشتراك فيرو: <الخطة>» (`veyro:<plan>`).
  - **السعر:** يجي من خطة فيرو باللوحة. سعر المنتج بالمتجر ما ينستخدم إلا لو سيرفر فيرو ما رد.
  - **خصم مشتركي الألعاب:** «خصم مشتركي منصة الألعاب (٪)» بكل خطة، والافتراضي 30٪ لكل الخطط (`GAMES_DISCOUNT`). ينطبق تلقائياً بالمتجر على أي حساب اشتراكه بالألعاب فعّال، وكل ما يشتري، طول ما هو مشترك. الخصم ينحسب بسيرفر الألعاب (`backend/store/veyro-link.js`)، والسعر الأصلي يطلع مشطوب.
  - **التفعيل:** بعد الدفع، سيرفر الألعاب يرسل الطلب لـ`POST /api/veyro/internal/store-grant`، ومعه السر `VEYRO_STORE_SECRET` (نفس القيمة بالخدمتين). فيرو يفعّل الخطة ويسجّل المبلغ المدفوع. لو فيرو ما رد، الطلب يتعاد إرساله كل دقيقتين (`veyro_store_grants`)، والمكرر ما يتفعّل مرتين.
  - **المحرر:** «فعّل اشتراكك» (ومن سطر الاشتراك تحت الحساب) تعرض الخطط بسعر الحساب وزر «اشترك من المتجر». وسيرفر الألعاب يرسل `games_subscriber` مع `/api/veyro/whoami`.
- **الدفع اليدوي:** باقي موجود. الأدمن يسجّل الدفعة من «تجديد» أو «منح اشتراك» مع المبلغ.

## التطوير

- **تعديل يخص فيرو:** بـ`veyro-server/` و`veyro/` و`js/agp-stream-overlay.js`.
- **ملفات منسوخة:** بعض ملفات `veyro-server/` منسوخة من `backend/` (اتصال تيك توك،
  إحصائيات البث، الشاشات، Streamlabs). تعديل ملف منها بسيرفر الألعاب **ما ينتقل لحاله**:
  - لو التعديل يخص فيرو، سوّه بالنسختين.
  - الفروق عن الأصل مكتوبة بتعليق `فيرو:` داخل كل ملف.
- **التشغيل محلياً:** `cd veyro-server && npm install && CORE_API_URL=http://localhost:8787 node server.js`
  (المنفذ الافتراضي 8788). لتجربة النقل: نفس `VEYRO_EXPORT_SECRET` بالسيرفرين.
- **الاختبارات:** `cd veyro-server && npm test`.

## بعدين (اختياري)

- لما يتفتح فيرو للكل (`PREVIEW_ADMIN_ONLY = false`):
  - `overlay/index.html` يتحوّل لـ`veyro/`.
  - هو الحين باقي يشتغل على سيرفر فيرو، لأن الستريمرز غير الأدمن يستخدمونه.
- بعد ما تستقر الأمور أسابيع: يقدر ينشال كود الشاشات القديم من `backend/`
  (`stats/stream-screens-service.js`، `screen-media-service.js`، `screen-audio-*`، `streamlabs/`،
  ومساراتها بـ`auth-router.js`) ويبقى الجسر (التحويل) بس.
