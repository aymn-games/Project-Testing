حرب الفرقين — دفعة 1 (الإعدادات + اللوبي + لوحة المشاركين)
================================================================

الملفات:
- index.html      : صفحة اللعبة (تحمّل AGP Core + agp-team-war.js)
- agp-team-war.js  : كل منطق اللعبة (الدفعة الأولى)
- style.css        : الستايل (هوية المنصة نفسها)

خطوات الرفع (GitHub Web UI):
1. أنشئ مجلد جديد: games/team-war/
2. ارفع الملفات الثلاثة داخله بنفس الأسماء
3. عدّل index.html الرئيسي (بجذر المشروع) — أضف بطاقة اللعبة الجديدة
   (السطر جاهز بالرسالة اللي معاها هذا الملف)

ما اللي شغّال الحين:
- شاشة إعدادات: يوزر تيك توك + اسم/كلمة مفتاحية لكل فريق + نقاط البداية
  (150/200/300/مخصّص) + مؤقت الاختيار (20/25/30/إيقاف)
- اتصال حقيقي بتيك توك عبر AGP.streamConnector الموجود أصلاً
- لوبي بتبويبين حيّين — أي مشاهد يعلّق بالكلمة المفتاحية ينضم فوراً لفريقه
- زر ⚙️ بالهيدر: لوحة مشاركين، حذف أي لاعب من المباراة بدون ما يأثر
  على النقاط أو باقي اللاعبين
- شاشة مباراة أولية: لوحة نقاط شغّالة فعلياً (تقدر تعدّلها يدوياً بالتجربة)

اللي لسه ناقص (الدفعة الثانية القادمة):
- شبكة المربعات المرقّمة + مؤشر الدور الحي
- سحب البطاقة العشوائية (صورة + رقم) عند كتابة رقم المربع بالشات
- تطبيق الخصم التلقائي (موجب يضر الخصم / سالب يضر نفس الفريق)
- كشف الفوز التلقائي عند وصول فريق للصفر + شاشة فوز

ملاحظة: اسم اللعبة "حرب الفرقين" مؤقت — غيّره بسطر واحد بأعلى
agp-team-war.js (متغيّر GAME_NAME) لأي اسم تفضّله.
