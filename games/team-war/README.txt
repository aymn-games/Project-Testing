حرب الفرقين — النسخة الكاملة (الإعدادات + اللوبي + شاشة اللعب + الفوز)
========================================================================

الملفات:
- index.html        : صفحة اللعبة (تحمّل AGP Core + خط Zain + agp-team-war.js)
- agp-team-war.js    : كل منطق اللعبة (كل الشاشات)
- style.css          : الستايل الكامل حسب مواصفات Figma
- images/crown.webp  : صورة التاج (شاشة الفوز)

خطوات الرفع (GitHub Web UI):
ارفع كل شي (بما فيه مجلد images/) داخل games/team-war/ بمستودعك، بنفس
الأسماء والهيكلة.

رابط الرفع المباشر:
https://github.com/aymn-games/Project-Testing/upload/main/games/team-war

بعد الرفع والـCommit، جرّب مباشرة على:
https://aymngames.online/games/team-war/index.html

الشاشات المكتملة:
1. الإعدادات — يوزر البث، اسم/كلمة كل فريق، الحد الأقصى للاعبين
   (٢ضد٢/٤ضد٤/٨ضد٨)، نقاط البداية (١٥٠/٢٠٠/٢٥٠)، مؤقت الاختيار
   (٢٠/٢٥/٣٠/إيقاف)، بالألوان والقياسات المحددة بالضبط
2. اللوبي — بانر التعليمات، تبويبا اسم/كلمة كل فريق، لوحتا الفريقين
   (٨٠٠×٦٠٠) بالتدرّج اللوني، شبكة بطاقات لاعبين (٢×٤)، زر بدء الجولة
3. شاشة اللعب (تصميمي الخاص) — شبكة ٤٨ مربع مرقّم، مؤشر دور حي بعدّاد
   تنازلي، سحب بطاقة عشوائية (٢٠ رمز مختلف) عند كتابة رقم المربع بالشات،
   خصم تلقائي (موجب يضر الخصم / سالب يضر نفس الفريق)
4. لوحة إدارة المباراة (زر ⚙️) — صندوق ينزلق من اليسار، حذف لاعب فردي،
   لوبي فرعي لتعويض مقعد فاضي بكل فريق (معطّل إلا لو فيه مقعد فاضي)،
   زر إنهاء المباراة
5. شاشة الفوز — تاج + بطاقات الفائزين (تكبر تلقائياً لو الفريق أصغر
   من ٨)، ٣ أزرار (إعادة بنفس اللاعبين / إنهاء والعودة / مباراة جديدة)

ملاحظة: شاشة اللعب نفسها (الشبكة/الأدوار/كشف البطاقة) من تصميمي الخاص
لأنه ما كان عندك مصمم لها بعد — جرّبها وقولي أي تعديل تبيه (شكل الشبكة،
الرموز المستخدمة، نطاق النقاط، مدة عرض البطاقة، إلخ).
