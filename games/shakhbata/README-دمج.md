# شخبطة v2 — مطابقة لنمط الخزنة الفعلي

هذي إعادة كتابة كاملة بعد ما قريت كود `agp-khazna.js` و`style.css` و`index.html` الفعليين. النمط الآن مطابق تمامًا لطريقة تحميل وربط الخزنة: نفس ملفات `<script>` بـ index.html، نفس namespace ‏`window.AymanGamesPlatform`، ونفس الخدمات (`AGP.player`, `AGP.playerCard`, `AGP.streamConnector`, `AGP.events`, `AGP.gameManager`).

## اللي مأخوذ بالحرف من كود الخزنة (مؤكد 100%، مو تخمين)
- ترتيب تحميل ملفات `<script>` بـ index.html
- `normalizeArabicText` لتطبيع النص العربي
- نمط شاشة الإعدادات "settings-no-box" (كلاسات وهيكلة مطابقة، بس بريفكس `shk-` بدل `kz-`)
- تبويب الاتصال بالبث (`AGP.streamConnector.connect('tiktok', {...})` + الاستماع لـ `stream:statusChanged`)
- شاشة اللوبي والانضمام عبر الكلمة المفتاحية (`stream:commentReceived` + `AGP.player.addPlayer/removePlayer`)
- الدرج الجانبي ولوبي إضافة لاعبين جدد أثناء المباراة (نفس التتابع بالضبط)
- شاشة الفائز عبر `AGP.playerCard.renderTrophyCard` + `window.AGPAuth.reportRoundCompletion`

## نقطتين مو مؤكدتين 100% — لازم تتحقق منهم بنفسك
1. **AGP.timerManager**: بالجزء اللي قريته من كود الخزنة، المؤقتات كانت `setTimeout`/`setInterval` عادية، مو عبر `AGP.timerManager` (رغم إنه مذكور بالخدمات المُعاد استخدامها بالتعليق). سويت نفس الشي هنا (`startRoundTimer`/`stopRoundTimer` بـ agp-shakhbata.js). لو فعليًا فيه معيار يفرض المرور عبر `AGP.timerManager`، سهل تستبدل هالدالتين بس.
2. **category بتسجيل اللعبة**: حطيت `'drawing-guessing-games'` كتخمين معقول، ما شفت قائمة الفئات المعتمدة الفعلية بمشروعك. غيّرها لأي فئة موجودة عندك فعليًا قبل الدمج.

## آلية اللعب
- الستريمر يكتب الكلمة بمربع سري (`#shk-secret-input`) ويضغط "ابدأ الرسم" → يبدأ المؤقت ويصير الرسم مفعّل
- أي تعليق بالشات من لاعب **منضم مسبقاً عبر الكلمة المفتاحية** يتحقق منه بمطابقة تقريبية (`isCloseEnoughGuess` — نفس أسلوب التطبيع العربي المستخدم بالخزنة + مسافة ليفنشتاين لتحمل خطأ إملائي بسيط)
- النقاط: أول تخمين صح = 3، الثاني = 2، الباقي لين العدد المحدد بالإعدادات = 1 لكل واحد
- الجولة تنتهي تلقائيًا إذا وصل عدد المُجيبين للعدد المحدد، أو ينتهي الوقت
- بعد آخر جولة، تظهر شاشة الفائز بأعلى مجموع نقاط، بنفس نظام `reportRoundCompletion` الحقيقي

## ملفات الرفع
`index.html`, `style.css`, `agp-shakhbata.js` — ارفعهم بمسار `games/shakhbata/` (نفس مستوى `games/khazna/`).
